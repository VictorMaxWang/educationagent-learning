# educationagent

面向乡村学生，尤其关注留守儿童学习与成长的单人学习工作台。沿用项目原有对话、练习、错题和成长知识功能，增加可以听、可以提问、可以动手探索的微课。

网站入口：<https://smartchildcareagent.cn>，免登录直接使用；当前公开工作台共用学习记录。

## 已实现的学习流程

输入主题或上传 PDF、Word、文字资料，选择小学至高中的年级，先确认可编辑大纲，再生成图文讲解、互动实验和随堂选择题。互动支持二维模拟、关系图、基础三维场景、知识游戏及 JavaScript 编程练习；编程代码在可终止的浏览器 Worker 中运行。课堂支持语音讲授、暂停重听、按键录音提问、一位明确标识为 AI 的学习同伴，以及学习位置恢复。

随堂题复用原有题库和错题记录。成长课堂以“小禾姐姐 AI”提供八类适龄话题、猜你想问、知识库检索与语音问答；对话保存在当前浏览器，按年级分开。微信通过一次性配对码连接工作台，提供课程链接和课堂提问。

课件支持对象点选提问、AI 修改、可视化拖动缩放、文字与表格编辑、公式和图片插入、撤销重做，以及课堂白板。老师能调整真实互动控件、标注和绘制白板；操作收到浏览器确认后才记录成功。图片使用独立图片接口生成并缓存，不调用视频模型。

课程可导出可编辑内容的 PPTX、独立 HTML 和课堂 ZIP。HTML / ZIP 可选择附加老师配音；ZIP 可重新导入为新课程与新试卷，不覆盖原成绩。MP4 入口暂未开放。

全局“小禾语音”悬浮球支持先转写、确认后提问与朗读，沿用当前课堂或成长话题；默认音色为 `403005 · 云雅琴`。录音与不同页面的朗读共用音频协调器。更多工具集中保留旧学习入口、设置、主题和本地音乐；本机版本继续保留原完整模块，公共英语提供情景剧本、语法与跟读练习。

团队成果实验室提供阵列失效对照、合成图像滤波和五项学习资源评价。课堂增加可选学习自述、三态操作回执、绑定内容的检查记录与失败插图局部重试。原文来源、公式及设计借鉴范围见[团队成果参考与代码映射](docs/团队成果参考与代码映射.md)。

## 技术结构

- Java 21 / Spring Boot：业务 API、模型配置、MySQL 持久化、题库与语音。
- React / TypeScript / Vite：网页课堂；现有 Tauri 桌面外壳继续保留。
- `course-engine`：Node.js 按任务生成课程，通过 JSONL 回调 Java 模型。
- `vendor/educationagent`：本地课程契约、生成器、画布渲染器与编辑器，无需另行运行 Next.js 或 PostgreSQL。

文本模型统一使用 OpenAI 兼容配置 `AI_CHAT_BASE_URL`、`AI_CHAT_API_KEY`、`AI_CHAT_MODEL`。当前接入模型为 `qwen3.8-flash`。语音与向量检索使用独立配置。

## 运行与配置

需要 JDK 21 或兼容版本、Node.js 22.19 以上、MySQL，以及所需的模型与语音凭据。配置模板见 [deploy/.env.example](deploy/.env.example)，真实密钥通过环境变量或本机忽略文件注入。

Windows 首次构建：

```powershell
./scripts/Build-Classroom.ps1 -InstallDependencies
```

日常开发可分别运行 Java 后端与 `desktop-app` 的 Vite。手机录音需要受信任 HTTPS。具体步骤见 [课堂运行指南](docs/课堂运行指南.md)；服务器配置见 [服务器部署说明](docs/服务器部署.md)。
