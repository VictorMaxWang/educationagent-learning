# 旧版功能与公网接口恢复审计

日期：2026-10-16。依据本地当前源码、前端实际请求和 `deploy/linux/Caddyfile`；本报告没有探测服务器、供应商账户或读取私密配置。公网实际放行结果由部署后的 HTTP 验收确认。

## 1. 旧功能没有从项目删除

原有组件与后端仍在。`desktop-app/src/App.jsx` 的 `VITE_PUBLIC_CLASSROOM === 'true'` 曾让整个旧导航不渲染，并不给课堂传入“打开工具导航”的回调，因此公网用户看不到入口。本机默认构建仍保留这些功能。

| 原导航 | 仍存在的内容 | 公网恢复方式 |
|---|---|---|
| 智能对话 | `ChatWindow`、会话历史、全工具 Agent | 保留本机；不能把原全工具聊天接口直接匿名开放 |
| 在线学习 | 刷题、错题、知识中心、代码练习、英语、通识、心理学 | 学习 REST 接口逐项恢复；公网代码使用浏览器隔离执行 |
| AI 普惠教育 | 生命安全、青春期教育、班级作业、学习周报、教师工作台 | 公共课程可恢复；真实班级/教师数据继续按身份访问 |
| 办公工具 | 格式转换、发票识别、图片水印、法律检索 | 复用原组件；有额外依赖的部分须先验收后端 |
| 旅行规划 | 行程、穿搭、酒店、餐馆、地图 | 普通生成/只读检索可恢复；任意 MCP 调用不开放 |

| 萌宠日常 | 档案、健康记录、日常记录、定时推送 | 静态知识查询可公开；个人记录与推送需身份边界 |
| 生活企划 | 小红书发布、登录、定时任务、评论监控 | 本机/受控管理入口保留，不能匿名开放共享账号操作 |

## 2. 当前网关范围与恢复清单

审计时的本地 Caddy 白名单是 `/api/classroom`、`/api/classroom/*`、`/api/desktop/quiz/*`、`/api/desktop/psychology/*`、`/api/desktop/lifesafety/*`、`/api/desktop/sexedu/*`、`/actuator/health`。随后 `/api/*`、`/chat/*`、其他 `/actuator/*` 被拒绝。

新增允许规则必须排在这个拒绝规则前。现场复核已收紧下表：知识中心和英语共享词库没有服务端身份隔离，不能按初稿的功能名称直接匿名恢复。不使用整个 `/api/desktop/*`、`/api/maimemo/*`、`/api/*` 或 `/chat/*`。

### 本轮公共恢复的精确路径

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/classroom/resources/{domain}/health`、`/libs` | `domain`仅允许`tongshi/psychology/lifesafety/sexedu`，两个短路径均接在对应领域后；仅返回公开准备状态与子库名称 |
| POST | `/api/classroom/resources/{domain}/search`、`/clear-context` | 新无历史包装：忽略客户端`uid`，服务端随机临时会话并在`finally`清理；清除接口为兼容页面的无状态成功响应 |
| GET | `/api/maimemo/config`、`/api/maimemo/speech-preset` | 只恢复这两个英语GET端点；`config`当前仅返回状态码，不返回账号配置 |
| POST | `/api/maimemo/grammar-quiz`、`/api/maimemo/speech-evaluate`、`/api/maimemo/speech-dialogue` | 只恢复这三个英语POST端点；不访问现有共享词库/复习状态，不执行墨墨云同步；口语仍使用现有讯飞ISE |
| POST | `/api/desktop/watermark/add`、`/api/desktop/watermark/remove` | 对请求中的图片做内存处理，不读取服务器任意路径 |
| POST | `/api/desktop/file/upload` | 为原刷题上传精确放行；成功仅返回随机`fileId`，不返回服务器路径或已有文件内容；缓存已增加上限与TTL |

以上四域资源入口已在现有`/api/classroom/*`范围内，由新controller再次验证领域/子库白名单与2000字符问题上限。公开`CourseKnowledgeView`切换到新基址；本机继续使用旧领域接口。原有课堂、练习及三类旧公共领域路径本轮不额外扩大，不能据此视为已经完成全站身份隔离审计。

**以下初稿建议已撤回，继续留本机或认证入口：**

- 知识中心六个`POST /api/desktop/knowledge/{save,list,view,delete,search,ask}`直接信任请求`userId`。路径穿越修复只能保护目录边界，不能阻止冒用用户ID读取或删除资料。
- 英语`generate/import/notebook/update-status/review-answer`直接改共享词库/复习数据；`words/review-stats/review-today`及听写、听力读取共享状态；`lookup-word/lookup-text`附带共享`inLibrary/inNotebook`标志。因此不能匿名恢复完整英语页。
- `/api/maimemo/sync`与请求`syncToMaimemo:true`的`/add-words`会写入部署者的墨墨云账号，继续拒绝。
- 旧通识/法律`search(uid)`会将`uid`对应的服务器历史送入模型，`clear-context(uid)`可删除该历史；仅有浏览器随机ID不能等同身份授权。本轮法律保持本机，四个公共教育领域改走新无历史包装。
- `POST /api/desktop/fileconvert/convert`保持本机，本轮不新增公共转换入口。`file/upload`在缓存有界后由主控批准精确恢复，供原刷题页面使用；不因此开放全工具聊天、知识库保存或转换接口。HTTP请求解析的临时内存与转换引擎仍需各自验收。

真实班级、个人资料、成绩及旧共享词库的多用户部署仍需要服务端身份绑定，本轮没有新增整站登录。

## 4. 本轮已完成的必要恢复修复

### 知识库文件名与目录

修复前，`UserKnowledgeService.saveAndIndex` 直接执行 `userDir.resolve(上传原 fileName)` 后写盘，上传者可构造目录或跨平台绝对路径。现在：

- 写入前拒绝 `/`、`\\`、冒号、控制字符、Windows 保留名称、尾随点/空白等不安全文件名；普通中文名称保留。
- 先解析真实知识库根，再验证用户目录留在根下；允许发布目录正常使用共享 `data` 链接，但拒绝用户子目录越界。
- 文件候选再次 `normalize` 并核对父目录；`CREATE_NEW` 防止并发或链接覆盖既有文件。
- 查看、删除、列表同样只接受该用户目录中的普通文件，不跟随文件符号链接。
- `KnowledgeController` 收到保存失败时返回 HTTP 400，而不再把失败话术包装为成功。

对应回归：`UserKnowledgeServiceTest`。本轮没有读取用户现有文档或修改已有知识库数据。

### 地图代理

`AmapProxyController` 现在只允许：


忽略客户端的 `key/sig/jscode/callback` 保留参数；日志只记录允许的路径和异常类型，失败向前端返回稳定中文提示。对应回归：`AmapProxyControllerTest`。

### 公共资源包装与上传缓存

`ClassroomResourceController`提供四域公共包装：`health/libs`只返回允许字段；`search`不接受旧`uid`作为身份或会话键，每次生成随机临时ID，结束、返回失败或抛异常均清理该ID。安全关键词先短路；后置内容校验判不适合时同时替换答案并隐藏本批原文片段。`clear-context`不操作旧会话。对应`ClassroomResourceControllerTest`，本地单测由主控统一执行。

`DesktopFileStore`保持`get`不消费与多格式转换兼容，同时增加单文件30 MiB、进程内64 MiB、最多64条、15分钟绝对TTL。所有访问在同一锁内清理过期数据并调整字节计数；总容量不足返回429，缓存层单文件超限返回413。原上传controller的提前检查仍返回400，因此不能把缓存层413等同HTTP上传端点413；Base64请求解析的临时内存也不由缓存总量限制覆盖。本轮仅精确开放上传，转换仍在本机。静态确认上传成功响应仅含随机`fileId`，该路径不读取原有文件，日志不输出文件字节（仅大小、ID、客户端提供的名称和MIME）。对应`DesktopFileStoreTest`，未新增依赖或后台线程。

### 前端同源请求

以下旧模块已复用 `api/baseUrl.js`，避免公网构建产生 `undefined/api/...`、错误访问访问者本机 `localhost:8888` 或 HTTPS 混合内容：

- `src/request.js`（英语 API）、`travel/request.ts`、`travel/MapView.tsx`。
- `tools/invoiceRequest.ts`、`tools/LawRagView.jsx`、`tools/WatermarkView.jsx`。
- `health/utils/amap.js`、`health/utils/wechat-bot.js`、`health/components/HealthConsult.jsx`、`health/components/MealPlanner.jsx`。
- `life/LifeView.tsx`、`pet/petApi.js`。

两处地图 `new URL()` 补上当前站点 origin；健康模块 `/ip` 等短上游路径统一补为 `v3/ip`。显式保存的本机微信自定义配置继续保留。没有改 App、课堂前端、CSS、音乐组件或运维 API。

音乐 `src/api/music.ts` 仍默认访问独立的 `http://localhost:3000` 网易云代理。当前 Java 与本地 Caddy 模板没有对应音乐代理服务，且 HTTPS 页面不能依靠该 HTTP 默认值播放。前端可恢复浏览器本地音频播放作为可用补充；网易云功能继续保留，需要部署并配置 HTTPS 音乐 API 后单独验收。

## 5. 统一语音

新默认音色为 `403005`（云雅琴）；主控已核对腾讯官方音色列表，其采样率包含当前的 16 kHz。代码继续使用 `TextToVoice`、API 版本 `2019-08-23`、`Codec=mp3`，不把语音请求交给聊天模型。

- 全局配置：`TENCENT_TTS_VOICE_TYPE=403005`、`TENCENT_TTS_SAMPLE_RATE=16000`。
- 教师与学伴默认继承全局声音；可选 `CLASSROOM_VOICE_TEACHER_VOICE_TYPE`、`CLASSROOM_VOICE_PEER_VOICE_TYPE` 明确覆盖。
- 成长问答复用课堂朗读入口，因此沿用相同音色。
- 新用户设置以空音色表示继承服务器配置；已有非空用户选择不迁移、不覆盖。
- 缓存键继续包含实际音色 ID、采样率和完整分段文本，换音色不会误播旧缓存。
- `/api/classroom/voice/health` 附加实际音色 ID/名称和采样率，不返回凭据。

官方表：<https://cloud.tencent.com/document/product/1073/92668>。真实云端合成与浏览器播放由主控验收，本审计未发起外部请求。
