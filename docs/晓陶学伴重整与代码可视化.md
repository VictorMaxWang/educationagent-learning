# 晓陶学伴：学习、成长与实践

项目名称：晓陶学伴——践行“教学做合一”的乡村学生个性化学习智能体。AI 学伴称小陶，网站朗读沿用 Cherry·芊悦。

## 导航与课程方向

成长课堂按心灵与沟通、安全与健康、语言与通识、实践与创造组织；原细话题、知识库和英语按学习目的归类。更多工具保留技术与参考、图片水印等已核准入口，非首页工具按需加载。团队成果实验室已于2026-10-17下线，原始资料和真实课堂算法保留。技术页独立滚动，可通过键盘及来源锚点访问完整内容。

新课程的 `direction` 为 `academic`、`wellbeing`、`exploration`。只有学科学习提交用户所选学科；旧 `domain` 保留知识库和导入兼容。成长共享历史使用 `edu_growth_conversation` 的年级与大类联合主键，公开只读；准备脚本调用真实问答后只补缺失记录。个人续聊仍在当前浏览器中隔离保存，旧记录迁移不删除来源。

## 代码可视化

`POST /api/classroom/code/jobs` 提交单文件程序和标准输入，`GET /{id}` 查询、`DELETE /{id}` 取消。浏览器通过 HttpOnly 凭据隔离任务。取消即时生效；`tracePending` 说明最后快照仍在收尾，客户端持续读取但不恢复运行状态。

四语言分别使用 Node Inspector、CPython sys.settrace、GDB/MI、JDI 收集真实轨迹。图形和逐步播放共用同一轨迹，修改代码或输入必须重算。运行错误、无法读取的值、截断和取消明确显示，不能以预设动画替代执行。

专用 Docker daemon 使用 `/run/xiaotao-code/docker.sock`，不启动默认 Docker 服务、桥接、iptables 或 IP 转发。构建阶段使用宿主网络下载官方依赖，每个学生任务固定无网络、非 root、只读根目录和专属 tmpfs；不挂业务目录、凭据或 Docker socket。编译与追踪预算为20秒/15秒，每任务1CPU、768MiB、128进程、1000步、64KiB输出，全站单并发且课堂生成优先。Java业务层的60秒通信预算仅允许运行器完成受限停止和回传快照。

运行器安装说明见 `code-runner/README.md`；来源与许可证见 `course-engine/upstream/openmaic-practice/SOURCE.json` 和其 LICENSE。OpenMAIC 的代码练习字段、提示和互动教学结构经宿主适配；四种调试适配器为本项目实现。

## 五题型与成绩

课堂题型为 `single/multiple/judge/fill/short_answer`，映射既有题库 `single/multi/judge/fill/short`。简答使用参考答案和评分要点进行语义评阅，未知或失败时整组回滚，不写成错误答案。离线简答仅展示参考与要点，选择、判断、填空可本地检查。

导入导出按题型保留文本、数字标答；公开课程不包含参考答案或评分要点。旧学伴身份仅在页面、朗读和导出深副本中兼容显示，不批量改写原课程、题干或用户原话。

## 发布验证

每次发布保存实际构建、定向检查、运行器实测、线上课程及错题验收记录。全量测试如被本机数据库或历史夹具阻断，必须单列失败证据，不把构建成功等同于测试全部通过。发布采用受审查的源码白名单，不发布密钥、原始资料、运行数据库或演示视频。
