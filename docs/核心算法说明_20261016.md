# 晓陶学伴：补充资源组合推荐与学习核对算法

版本：2026-10-16；算法标识 `classroom-combination-v1`。本说明按本轮源代码编写，最终构建、线上结果与提交号以[本轮便携证据清单](research-20261016/README.md)为准。权重是公开的工程默认值，不是所引用论文已经证明的最优教学权重。

## 1. 解决的问题和数据边界

现有课堂已经提供课件、动画、代码执行、语音和练习。补充推荐只解决“当前任务是否适合观看外部示范，以及有限时间内看哪几段”的问题。把教学适用性、资源存在性、内容匹配和组合选择拆开，可分别解释失败原因并验证每一步。

输入是课程主题、方向、年级、当前章节、服务端资料锚点、明确的用途偏好和时间预算。公共搜索词仅由公开课程主题和教学用途构造，不包含年级标签、附件全文、私人对话或个人经历。年级仍用于服务器内的适龄判断。当前错题判分、具体代码调试和私密成长对话优先由原课堂处理。

分类状态为 `eligible/ineligible/uncertain`。NLP输出必须引用当前课程中真实存在的依据；输出不确定、接口故障和资源核验失败时不展示视频区域。模型的结构化判断属于模型输出，不解释为统计置信度。

## 3. 有限候选组合优化

候选最多20条，选择1—3条，最多枚举 `C(20,1)+C(20,2)+C(20,3)=1350` 个非空组合。候选使用 `BV号:分P` 稳定ID。组合必须满足适用性、正整数时长、总时长预算、无重复ID、无重复转载组。上游负责核验真实视频、年级与主题相容性；纯算法只接收已经附带这些判断的候选。

设本课目标集合为G，候选i覆盖的目标为G_i，组合为S：

\[
C(S)=\frac{|G\cap\bigcup_{i\in S}G_i|}{|G|},\quad
R(S)=\frac1{|S|}\sum_{i\in S}r_i,\quad
M(S)=\frac1{|S|}\sum_{i\in S}m_i,\quad
P(S)=\frac1{|S|}\sum_{i\in S}p_i.
\]

语义相关度 `r_i` 为课程公开查询与资源元数据向量的余弦值截断到[0,1]；`m_i` 为该资源对当前课堂用途的补充程度；`p_i` 仅表示本次明确用途偏好。候选特征与匹配依据必须随决策保存，不能把这些特征当作学生能力测量。

当前实现将诵读、发音、听力、观察和步骤示范的 `m_i` 设为1；其余概念/例题用途在当前课已有讲解时为0.5，否则为0.8。`p_i` 为元数据核对输出的明确偏好匹配标记0/1。这些值是公开的启发式特征，后续可在开发集验证后版本化更新，不能称为经学生实验估计的学习收益。

\[
D(S)=\begin{cases}0,&|S|=1,\\
\frac{\sum_{i<j,\ i,j\in S}\mathbf1[u_i=u_j]\,s_{ij}}{\binom{|S|}{2}},&|S|>1.
\end{cases}
\]

`u_i` 为教学用途。不同用途的对在分子贡献0，但仍计入全部无序对分母，使“同知识点、不同示范用途”可互补。向量相似度缺失时纯算法回退为目标集合Jaccard；两个目标集合都空时按1处理，不能把未知相似度解释为确定不重复。业务层正常路径提供实际向量相似度，并记录来源。

有明确偏好时：

\[
J(S)=0.40C+0.30R+0.20M+0.10P-0.20D.
\]

没有明确偏好时，停用P，仅对正向权重重归一：

\[
J(S)=\frac{0.40C+0.30R+0.20M}{0.90}-0.20D.
\]

总时长预算默认为600秒，支持300/600/1200秒。未知时长不以0秒参与优化。特征先量化到1e-4；均值、覆盖和最终分数以1e-6整数单位、HALF_UP计算，避免浮点累加顺序影响结果。相同分数依次选择总时长更短、重复度更低、排序后ID字典序更前的组合。

无目标、无候选或没有可行组合返回空选择；结构错误、重复候选ID和非有限特征直接拒绝。知识库片段的 `EvidenceSelector` 保持独立职责。

## 4. 独立校验与差额复用

`RecommendationVerifier` 使用独立递归遍历、BigDecimal评分和约束检查，不调用优化器的 `select/evaluate`。它检查声称的分数是否真实、组合是否满足约束，以及是否为规则指定的最优解。复用组合允许不是最优，因此单独使用 `recompute` 检查可行性和实际分数。

每次旧推荐复用均在当前同一输入下重算：

\[
J^*=\max_{S\in\mathcal F}J(S),\qquad \Delta=J^*-J(S_{old}).
\]

仅当旧组合仍可行且差额不超过0.02，允许保留。上下文指纹、目标、年级、算法版本或资源来源改变后必须重新比较。纯算法返回“旧组合不可行”时的gap字段不构成有效差额证书，应以reason及复核状态解释。

本结论只覆盖当前有限候选池、量化规则、特征输入和目标函数。不能把它表述为推荐具有0.02以内的教学损失，更不能将向量相似度本身当作学习收益。

## 5. 离散首次命中相容性审计

两种排序分别为L、R，同一资源ID共用相关性标签，`true/false/null或缺失` 分别为适合、不适合、未知。将两排序资源并集中的未知标签枚举为0/1，共享标签的一次赋值同时用于两种排序。

\[
T(\pi,y)=\begin{cases}\min\{k:y_{\pi_k}=1\},&存在命中,\\|\pi|,&无命中,\end{cases}
\quad d(y)=T(L,y)-T(R,y).
\]

审计输出相容赋值中的 `min d` 与 `max d`，并保留达到端点的标签赋值。无命中与最后一项命中的数值成本可能相同，因此无命中赋值数另存。未知数最多12，即最多4096次赋值；超限或来源故障返回 `NOT_COMPUTED` 和原因，不填假零值。

区间是固定排序的检查次数差范围，不是概率置信区间，也不是M002连续空间的期望积分。没有给标签赋值指定概率分布，故不计算“期望改善”。该审计仅在离线工程评测中使用。

## 6. 来源约束的学习核对

M003 §5.3明确把learner-first summarising称为待评估设计。本项目保存首次表述及修订链，并将“表述、模型核对、提示级别、自检提交、外跳点击”分开记录。缺证据、跳过和自述信心均不转为错题或能力标签。

核对状态为covered/missing/conflict/uncertain。除不带引用的uncertain外，引用必须属于当前课程当前版本的真实资料/课件锚点，且quote是空白规范化后存在的连续原文。主题、学习目标本身不能充当知识事实证据。分层帮助按定位、提问、线索、示例解释顺序提供。

自检为独立一道单选/多选/判断/填空，复用已有判分事务；首次自主表述的语义核对使用有界模型调用。原课堂五题型保持原有功能。未知判分不提交错题，失败保留同一提交ID及答案供重试。内容指纹改变时旧反馈失效；播放进度、对白和运行时revision不使相同资料失效。

## 7. 可重复验证和结果解释

核心算法当前已有24项测试通过，日志为 `target/recommendation-core-check/test-results.log`；其中覆盖1350组合、量化、输入置换、独立验证、复用、共享unknown、无命中和13个unknown拒算。此结果只代表该次核心算法测试，不代替全量构建和正式网站验收。

最终评测使用72条分类夹具、30组真实检索快照和40组资料核对案例。固定输入比较原排序、语义单项排序、贪心组合、确定性组合，并分别移除适用性门控、语义、覆盖、重复、反馈目标。样本有来源和标签制作方式，保留失败分母。运行时必须分别记录搜索、模型、优化及端到端耗时。

优化器最优只意味着同一评分模型内不弱于贪心；是否更适合学生要由额外人评或学生研究检验。本轮不预填指标提升、不复用论文的实验数字作为网站成绩。
