## 真正需要恢复的行为

本次静态核对没有发现上表旧业务模块被整块删除。主要回归是公开版本只显示课堂、没有旧工具和设置的到达路径，以及固定课堂色板使原主题选择缺少可见效果。另一个容易混淆的点是：此前为避免讲课与音乐重叠，课堂不挂载原音乐浮窗；这不等于删除播放器，但确实需要可见的恢复入口。

本轮以“更多工具”恢复已核准入口，保留本机完整侧栏，并为旧工具页加入“返回学习课堂”。未核准的系统、账号、个人记录和执行能力继续留在本机，不用“功能恢复”作为扩大匿名接口权限的理由。

## 全局语音与验证边界

- `AudioCoordinator` 管理全局播放焦点、麦克风占用和授权等待保护；新播放停止旧播放，录音停止播放，另一处正在录音时不能抢占。旧 token 的释放不会清掉新会话。
- 课堂、成长课堂和语音球沿用 `NarrationQueue`；原生音乐/听力元素通过全局媒体事件参加互斥。切页、收起语音球和撤销麦克风等待会清理本次活动。
- 课堂语音提问使用当前场景、选中对象和即时互动状态，继续由 Java 校验；成长页复用其当前年级、话题和历史。其他页使用小禾姐姐 guide 服务。
- 识别完成只填写可编辑文字，不自动发送。没有 HTTPS/麦克风权限或服务未配置时，真实保留文字与 WAV 上传入口。
- 语音球识别最多等待 45 秒、问答最多等待 90 秒；取消或超时后晚到回复不会加入会话历史。移动键盘弹出时，面板高度随可视区域收缩。
- 公网英语最多使用 `GET /api/maimemo/config`、`GET /api/maimemo/speech-preset`、`POST /api/maimemo/grammar-quiz`、`POST /api/maimemo/speech-evaluate`、`POST /api/maimemo/speech-dialogue` 五个明确端点；实际功能及接口结果以运行验收为准。
- 这份文档不代替公开部署验证。主控仍需分别记录类型检查、单元测试、浏览器视觉/交互验证以及实际 API/路由验收结果。
