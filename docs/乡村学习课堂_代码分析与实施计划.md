# 乡村学习课堂：代码分析与实施计划

日期：2026-10-15。本项目的包、目录与产品统一使用 **educationagent** 命名。本文记录实施边界和实际验收结果。

## 1. 已确认的目标与范围

项目面向乡村留守儿童的学习与成长，覆盖小学至高中；学科学习和现有身心健康教育均保留。第一版增加的主线是 **资料或主题 → 微课大纲 → 语音讲解 → 互动与随堂练习 → 错题复习、继续学习**。

- 一位学习导师、一位明确标识为 AI 的学习同伴；同伴只在主动邀请或讨论节点发言，不建立复杂多智能体调度。
- 网页提供完整课堂，兼容现有 Tauri；微信提供课堂入口与学习提问。同一 Wi-Fi 优先，手机录音通过受信任 HTTPS 验证。
- 单用户使用，不建设注册、招生、多租户、多班级系统。新课堂使用固定学习者标识 `classroom`，旧用户历史数据保持原样；课堂复习页复用现有错题组件读取该标识。
- 语音采用“点击开始授课，按句播放；点击录音，再点击结束，编辑转写后发送”。普通话为主，保留文字与字幕。
- 本期不做离线课包、实时全双工语音、视频生成、3D、PBL 项目系统、心情打卡或新的健康档案。
- 心理、生命安全与青春期教育沿用现有功能和资料框架，做入口整合和课堂年龄约束；不把成人健康养护模块改名当作儿童功能。

## 2. 两个项目的结构和实际复用边界

### 现有项目

| 层次 | 主要代码 | 当前职责及本次处理 |
|---|---|---|

| Agent | `agent/AgentExecutor`、`router`、`service/interrupt` | 统一模型、路由、工具和打断；保留原功能，主定位改为学习与成长助手；课堂复用模型 Bean 和安全服务，不额外运行旅行工具链 |
| 对话入口 | `listener/WechatMsgListener`、`service/CmdService`、`session` | 微信媒体预处理与网页会话；通过明确课堂指令接入课程，原有消息处理继续保留 |

| 前端 | `desktop-app/src/App.jsx`、`study`、`edu`、`chat` | React 19 / Vite / 部分 TypeScript，基于 activeView 导航；新增独立课堂模块，不更换前端框架 |
| 桌面外壳 | `desktop-app/src-tauri` | Rust / Tauri 2；保留现有原生能力，不在其中重写业务 |
| 数据 | MySQL、Redis、Chroma、Lucene、`data` | 保留现有存储；课程及恢复位置新增一张 MySQL 表，生成语音按内容缓存为本地音频文件 |

已核实的接入问题：长文 TTS 分段可能超过 150 字后被再次截断；浏览器录音与微信 AMR/SILK 格式不同；部分前端请求将手机的 localhost 误当服务器；当前全局 Agent 仍以旅行规划师为主；现有专题资料并非已审定的小学到高中课程库。

## 3. 实现方案与接口

### 生成与数据

Java 是网页的唯一业务 API。新增教育课堂服务，使用现有模型 Bean、文件解析、安全规则与题库。新增 `edu_learning_course`，保存课程 JSON、状态和更新时间；JSON 内保存大纲、已完成场景、当前学习位置和课堂短对话。生成每完成一页即保存，失败保留已完成内容；重试从缺失页继续。

Node 只运行生成任务，不开放端口、不接数据库、不保存模型密钥。Java 使用 `ProcessBuilder` 启动自身管理的进程，双方以 JSONL 交换 `job / llm.request / llm.result / result / error`；stdout 只传协议，stderr 接收日志。任务可以取消或超时，只结束当前任务拥有的进程；所有返回按请求 ID 匹配。

课程输入包含主题、年级 1–12、学科或教育专题、可选材料正文。默认短课约 10 分钟，生成 4–8 个步骤。先生成大纲，用户调整标题、内容说明和顺序后确认生成。内容限定为 `slide / quiz / interactive`；互动限定二维模拟与关系图。随堂题首版用单选和多选，以现有规则判分；自由回答通过课堂问答解释。

| API | 主要行为 |
|---|---|
| `GET /api/classroom/health` | 返回运行依赖与语音是否配置，不返回凭据 |
| `POST /api/classroom/materials` | 复用 FileService 提取 PDF、Word、文本；返回正文、文件名和截断提示 |
| `GET/POST /api/classroom/courses` | 列表；按主题、年级和材料创建大纲生成任务 |
| `GET /api/classroom/courses/{id}` | 获取课程、生成状态和已保存进度 |
| `PUT /api/classroom/courses/{id}/outline` | 生成正文前保存编辑后的大纲 |
| `POST /api/classroom/courses/{id}/generate` | 开始或恢复逐页生成；同一课程不重复并发运行 |
| `POST /api/classroom/courses/{id}/cancel` | 取消当前生成，保留已有内容 |
| `PUT /api/classroom/courses/{id}/progress` | 保存页和讲授动作位置 |
| `POST /api/classroom/courses/{id}/answer` | 根据课程关联的小测判分，作答进入已有错题体系；重复提交有请求去重 |
| `POST /api/classroom/courses/{id}/chat` | 带当前页、年级和最近课堂对话，请老师解释或邀请同伴回答 |
| `POST /api/classroom/voice/tts` | 返回有序语音片段及音频 URL |
| `POST /api/classroom/voice/asr` | 接收受限长度的单声道 WAV 录音，返回可编辑文本 |

参数、文件大小、生成结果和动作类型在边界处验证。课程问答使用显式教学上下文；儿童成长内容沿用现有安全分流，输出先完成短段检查再朗读。模型或资料不足时显示真实失败/来源缺失，不用预制文字冒充生成成功。

### 网页、语音与互动

- 新首页突出“开始一节课、继续学习、课堂错题”和已有成长知识入口。保留既有导航与工具，课堂有独立温和、清晰的视觉布局，不复制参考项目的整套课堂外观。
- 课堂采用目录、中央学习画布、下方字幕播放栏、可收起问答区；手机切为单栏。支持上一步、下一步、暂停、重听、语速调整、录音提问和 AI 同伴。
- 一个课堂只有一个活动音频队列；按实际播放结束推进。录音、换页、离开课堂立即停播，取消过期请求，旧音频返回后不能自行恢复播放。
- TTS 按句切成严格不超过接口限制的片段；片段失败显式重试，修复原长文方法漏读及静默跳过失败片段的问题。同样文字与音色复用音频文件。
- 浏览器采集单声道 16 kHz WAV，通过后端识别，保留微信原 ASR 签名与格式。权限拒绝、无麦克风或识别失败显示可操作提示，文字输入始终可用。
- 生成互动 HTML 在无 `allow-same-origin` 的沙箱 iframe 内播放；限制网络与跳转，只处理来自当前 iframe 的白名单消息。语法检查不当成安全隔离。

### 微信与运行方式

在既有 CmdService 中接入明确指令：“课堂帮助”“我的课堂”“继续学习”“课堂提问 …”。通过一次性配对码绑定一个微信发送者与单人工作台；未绑定发送者不能获得课程记录，原聊天不受影响。配对不建立账号系统。微信语音仍由原预处理链转写，课堂回答继续复用既有文字/MP3 发送链；不承诺原生语音气泡。

提供课堂网页启动脚本：构建后的静态网页与 API 走同源入口，Node/Java 和端口先检查。局域网手机录音使用 HTTPS；证书及手机信任步骤明确列在运行说明中，不自动修改系统代理、VPN 或全局证书信任。保留原桌面启动方式。控制台无 stdin 时后端保持运行。

## 4. 实施顺序与验收

1. 固定上游包与许可，完成生成任务桥和假模型契约测试；先证明生成结果能进入自定义画布。
2. 接课程持久化、文件材料、题库与课堂问答；测试大纲编辑、逐页生成、失败恢复、取消及题目去重。
3. 完成网页课堂、语音队列和 WAV 转写，接入原 App；修复本次涉及的手机同源请求问题。
4. 接微信配对/课堂命令和 HTTPS 运行入口，更新结构说明与使用文档。
5. 运行有针对性的 Java 单测、Node 契约测试、前端类型检查及生产构建；浏览器检查桌面/手机布局、播放中断、错误提示与互动隔离。

验收用例包括：小学分数、初中科学、高中函数的分龄课程；一节使用现有成长主题资料的课程；长句超过 150 字但朗读不丢字；中间语音失败不能跳过；重复提交不重复计分；模型输出非法 JSON、进程失败和超时可恢复；刷新后继续；录音期间不播放教师语音；旧刷题、知识库、聊天和工具仍可进入。

自动测试使用隔离数据与模型/语音替身，不让测试启动全量知识索引或写入既有学习数据。真实模型、语音供应商、手机权限和微信扫码分别标记实测状态；有配置不等于已验证可用。真实设备/外部登录无法自动完成时，保留可运行入口和准确的剩余验收步骤。
