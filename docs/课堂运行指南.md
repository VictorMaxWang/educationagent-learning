# educationagent 乡村学习课堂运行指南

课堂沿用现有 Java 后端和 React 前端。本指南说明 Windows 局域网入口：手机或电脑 → HTTPS `1443` → 静态网页 / 本机 Java `8888`。生成器由 Java 按任务启动，不需要另外启动 Node API 服务。

阿里云域名部署使用 Caddy 和 `server` 配置，参见[服务器部署](服务器部署.md)。公网入口是 `https://smartchildcareagent.cn`，手机不必与电脑连接同一 Wi-Fi。

## 1. 准备环境

- Windows PowerShell 7；Node.js ≥ 22.19.0；满足项目 Java 21 编译目标的 JDK，包含 `java.exe` 和 `keytool.exe`。Maven 使用仓库已有的 `mvnw.cmd`。
- 原项目 MySQL、Redis、知识库及模型配置按现有环境准备。运行脚本不安装数据库、不改系统 PATH、不修改代理/VPN/防火墙、不写入模型密钥。
- 当前代码默认启用 `dev` 配置。请核对自己的 `src/main/resources/application-dev.properties` 与 `application.properties`，保留原文件。启动整个 Java 应用可能执行既有数据库初始化与知识库索引逻辑，先确认原有依赖可用。
- 本版为单用户工作台。局域网 URL 会开放原项目的 `/api`、`/chat`、`/actuator` 对应接口，应只在本人管理的同一 Wi-Fi 使用；这里没有新增公网账号认证或端口转发。

所有命令在项目根目录 `D:\A-project\newbot_agent3.0` 的 PowerShell 7 中执行。

## 2. 首次构建与后续更新

首次安装依赖并构建：

```powershell
./scripts/Build-Classroom.ps1 -InstallDependencies
```

已有依赖时只构建：

```powershell
./scripts/Build-Classroom.ps1
```

脚本先在项目根目录安装/构建 workspace（`vendor/educationagent` 与 `course-engine`），然后构建 `desktop-app`，最后执行 Maven 打包。存在锁文件时用 `npm ci`；不带 `-InstallDependencies` 不会重新安装。Java 打包使用 `-DskipTests`，所以打包完成不代表测试通过。

修改范围较小时可以显式跳过未变部分，例如：

```powershell
# 只更新网页
./scripts/Build-Classroom.ps1 -SkipBackend -SkipCourseEngine
# 只更新 Java
./scripts/Build-Classroom.ps1 -SkipFrontend -SkipCourseEngine
```

主要产物为 `desktop-app/dist/index.html`、`course-engine/dist/worker.js`、`target/NewBot_Agent-0.0.1-SNAPSHOT.jar`。共享包发生变化时应重新构建生成器和网页。生成器构建同时产生本地 Three / 编程运行时；网页构建先产生离线播放器，不能省略这些步骤只复制旧 dist。

新增课堂操作说明见[课堂能力升级与验收](课堂能力升级验收_20261015.md)。服务器发布可用 `py -3.13 scripts/prepare-classroom-release.py --release-id <版本名>` 打包已构建产物；该命令不构建、不安装、不部署，也不携带本机数据。

## 3. 为手机生成 HTTPS 证书

手机浏览器的麦克风功能需要受信任的安全上下文。`http://192.168.x.x` 不满足此要求；电脑的 `http://localhost` 可用也不能证明手机可录音。

先查看当前 Wi-Fi 的 IPv4 地址：

```powershell
Get-NetIPConfiguration | Select-Object InterfaceAlias, IPv4Address, IPv4DefaultGateway
```

从输出中选用连接手机所在 Wi-Fi 的网卡地址，替换下面示例：

```powershell
./scripts/New-ClassroomCertificate.ps1 -LanAddress '192.168.1.20'
```

脚本使用 JDK `keytool` 在 `data/classroom/tls` 生成一套本地 CA 和有效期 365 天的服务器证书。服务器 SAN 包含 `localhost`、`127.0.0.1` 和指定 IP。目录权限限制为当前 Windows 用户；脚本不会将 CA 安装到 Windows 或手机信任库。

| 文件 | 用途 |
|---|---|
| `ca.crt` | 可传给自己的电脑/手机，用于手动信任本课堂 CA |
| `server.p12` | HTTPS 服务器私钥及证书链，只留在电脑 |
| `ca.p12` | 本地 CA 私钥，只留在电脑 |
| `tls.json` | 服务器证书配置及随机口令，只留在电脑，不提交或转发 |
| `server.csr`、`server.crt` | 证书生成过程中的请求与签发结果 |

把 **仅 `ca.crt`** 通过本人已有的文件传输方式送到手机，按该系统的证书管理流程安装并信任。iPhone/iPad 通常先安装描述文件，再到“设置 → 通用 → 关于本机 → 证书信任设置”对该 CA 开启完全信任，参见 [Apple 官方说明](https://support.apple.com/en-us/102390)。Android 入口随厂商和系统版本变化，在系统设置中查找“CA 证书”并按设备提供的安装说明操作。企业管理设备可能不允许自定义 CA，部分应用内浏览器也可能不采用用户安装的 CA。

电脑如需通过 `https://localhost:1443` 录音，也需由你自行信任 `ca.crt`。不要把跳过证书警告当作信任或录音验收成功。若设备不支持自定义 CA，仍可使用文字输入；本脚本没有设置公开域名和受公开信任的证书。

证书目录非空时脚本会拒绝覆盖。电脑 Wi-Fi IP 改变或证书到期后，可以生成新目录并显式选择它：

```powershell
./scripts/New-ClassroomCertificate.ps1 -LanAddress '192.168.1.30' -OutputDirectory './data/classroom/tls-next'
./scripts/Start-Classroom.ps1 -TlsDirectory './data/classroom/tls-next'
```

新目录会产生新的 CA，需要在设备上重新信任对应的 `ca.crt`。旧证书与旧信任项不会被脚本自动删除。

## 4. 启动、查看日志与停止

依赖已就绪、构建和证书已准备好时：

```powershell
./scripts/Start-Classroom.ps1
```

脚本检查端口，后台隐藏启动 Java，再检查 `GET /api/classroom/health`，最后启动 HTTPS。脚本新启动的 Java 绑定 `127.0.0.1:8888`，手机通过 `1443` 访问。默认不启动微信登录。

若 Java 已通过 IDE、Maven 或原桌面脚本启动，明确复用：

```powershell
./scripts/Start-Classroom.ps1 -UseExistingBackend
```

没有此开关且 `8888` 已被占用时，脚本会停止并显示 PID，不结束或接管未知进程。复用时要求本机该端口响应课堂健康接口；停止课堂脚本不会结束这个已有后端。

脚本会输出证书覆盖的局域网链接，例如 `https://192.168.1.20:1443`。手机与电脑连同一 Wi-Fi，在手机浏览器中打开该地址。该 IP 必须仍属于电脑；证书有这个 IP 不代表路由可达。如果 Windows 防火墙提示，由你决定是否允许对应 Node 程序在当前专用网络访问；脚本不创建防火墙规则。

运行记录和日志保存在 `data/classroom/run`：

- `processes.json`：本次 Java/Node 的 PID、进程创建时间、可执行文件路径和唯一运行标记。
- `<运行标记>-java.out.log` / `-java.err.log`：Java 日志与微信扫码链接。
- `<运行标记>-web.out.log` / `-web.err.log`：HTTPS 入口日志。

查看具体日志可以使用：

```powershell
Get-ChildItem ./data/classroom/run -Filter '*.log' | Sort-Object LastWriteTime -Descending
Get-Content -LiteralPath './data/classroom/run/<实际文件名>.log' -Tail 80
```

停止前先在课堂页面取消仍在生成的课程，然后执行：

```powershell
./scripts/Stop-Classroom.ps1
```

停止脚本核实进程创建时间、路径和运行标记，只结束本次记录的自有进程。记录与当前 PID 身份不符会拒绝操作；不按 `java.exe`、`node.exe` 通用名称批量结束。原桌面启动脚本 `start-desktop.bat` 继续保留。

开发时可继续使用原 Java 启动方式以及 `desktop-app` 中的 `npm run dev`。Vite 默认 `1420` 用于本机开发；普通局域网 HTTP 开发地址不等同于已受信任的手机录音环境。

## 5. 连接微信

新启动 Java 时如需同时开始一个微信机器人登录流程：

```powershell
./scripts/Start-Classroom.ps1 -StartWechat
```

这个开关只为本次 Java 进程传入 `--bot.auto-start-count=1`，不改配置文件。后台日志会显示项目原有 iLink SDK 生成的微信扫码链接，由你本人打开、扫码并确认。`-UseExistingBackend` 与 `-StartWechat` 不能一起使用；已有交互控制台则使用原命令 `bot start 1`。

机器人微信登录与课堂配对是两步：

1. 完成机器人原有扫码登录，确认它能收发消息。
2. 用**手机可达的局域网 HTTPS 地址**打开课堂首页，点击“连接微信”生成短期配对码。
3. 向机器人发送 `绑定课堂 配对码`。配对码有效期为 5 分钟，用后失效。
4. 可发送 `课堂帮助`、`我的课堂`、`学习课程 课程ID`、`继续学习`、`课堂提问 你的问题`。

首页配对时会保存当前网页入口。若从 `https://localhost:1443` 生成配对码，返回微信的课程链接也会包含 localhost，手机无法借此访问电脑；请从局域网入口重新生成并绑定。

微信语音仍走项目原有的音频预处理链，课堂回答复用原消息发送能力。完整画布、操作与网页录音在浏览器中使用；微信内置浏览器的证书和麦克风支持需单独实测，必要时选择系统浏览器打开。这里没有将网页 HTTPS 验收等同于微信登录或微信原生语音气泡验收。

## 6. 验证和问题定位

HTTPS 入口的隔离测试：

```powershell
./scripts/Test-ClassroomServer.ps1
```

测试只在 `target` 生成临时证书和网页夹具，用临时端口运行假的 Java HTTP 服务。覆盖真实 TLS 证书验证、静态资源/HEAD、SPA 回退、目录遍历和目录联接、固定上游代理、NDJSON 首段及时返回、客户端中止后关闭上游及后端故障 502。另检查 PowerShell 脚本语法和进程身份记录；不会启动项目 Java、触发数据库索引、安装系统根证书或调用真实模型。

生成器的独立测试入口：

```powershell
npm run test:classroom-engine
```

手机最后需要手工验收：证书无警告；页面可打开；点击录音后系统正常请求麦克风权限；再次点击结束；转写可编辑后发送；开始录音时讲课声音停止；切页和离开课堂不继续播放旧音频。扫码登录、微信配对与真实模型/语音服务需分别验收。

| 现象 | 检查位置 |
|---|---|
| `8888` 已占用 | 核实该 PID 的服务归属；确认是本项目后端后才用 `-UseExistingBackend` |
| Java 启动超时/提前退出 | 本次 Java 日志、MySQL/Redis 等原有依赖、项目配置；不反复盲目重启 |
| HTTPS 启动失败 | 本次 web 日志、证书目录及 `server.p12`，检查 `1443` 归属 |
| 手机打不开页面 | 同一 Wi-Fi、电脑当前 IP、网络是否隔离客户端、专用网络防火墙许可 |
| 手机提示证书错误 | 地址是否列在 SAN 中、CA 是否完全信任、服务器证书是否过期 |
| 页面可用但不能录音 | 浏览器安全上下文、麦克风许可、系统浏览器与微信内置浏览器的差别 |
| 生成器缺失 | 先在根目录构建 `build:classroom-engine`，检查 `course-engine/dist/worker.js` |
| 生成或语音报错 | `/api/classroom/health` 依赖提示和 Java 日志；配置存在不等于供应商调用成功 |

本次自动验收仅证明代码与隔离夹具中对应行为。手机 CA 信任、实际局域网连通、真实麦克风、微信扫码、真实模型和语音供应商尚需在实际设备和配置下验证。
