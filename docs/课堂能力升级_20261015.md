# educationagent 课堂能力升级

本次保持网页免登录、小学至高中、Java/MySQL 唯一持久化入口，以及已有练习成绩不被编辑覆盖。每个可运行批次完成检查后提交并推送 GitHub。

## 实施批次

| 批次 | 实际交付 | 验收重点 |
|---|---|---|
| 基线 | 推送当前版本；清理项目声明与旧名称展示 | 发布快照清敏、文件完整、远端提交一致 |
| 成长课堂 | 陪伴人格、分类猜你想问、基于知识库的问答与追问、语音 | 小学至高中分层；危险信号先兜底；记录留在当前浏览器 |
| 课件工作台 | 点选对象问答、完整幻灯片编辑、白板与老师实验操作 | 真正拖动/缩放/改文字和保存；引用校验；操作确认；修订冲突 |
| 课堂扩展 | 三维、知识游戏、编程互动、自动配图 | 沙箱、无服务器执行学生代码；图片真实生成并进入课件；不调用视频模型 |
| 导出迁移 | PPTX、单文件 HTML、课堂 ZIP、重新导入 | 内容和媒体齐全；离线可播放已有内容；重新导入建立新卷，保留旧成绩 |
| 可选视频 | 检查本地渲染能力后决定 MP4 开放方式 | 仅本地编码，不把下载 HTML 或 ZIP 当作视频导出 |

## 一致的对象与写入接口

课程增加 `revision` 与按场景保存的 `runtime`。讲授进度、聊天记录不增加内容修订号。编辑保存携带期望修订号，旧编辑结果不能覆盖新内容。

- 对象引用：`slide_element`、`interactive_component`、`whiteboard_element`；只传对象身份，正文由后端从真实课程解析。
- `PUT /api/classroom/courses/{id}/scenes/{sceneId}`：保存当前页的内容及动作；已关联试卷不直接改题。
- `PUT /api/classroom/courses/{id}/runtime`：保存白板、实验状态与动作执行确认；操作 ID 去重。
- `GET /api/classroom/courses/{id}/portable`：导出教材快照，包含离线题目答案，不包含聊天与提交流水。
- `POST /api/classroom/courses/import`：建立新课程、页面和题库标识，不导入历史成绩。

实验操作必须收到当前 iframe 的确认才算成功；换页后的旧消息无效。编程在浏览器隔离环境运行，不接通服务器命令执行工具。

## 验收记录原则

代码编译、单元检查、真实模型、真实图片、浏览器互动、导出文件结构、导入回读和服务器访问分别记录。外部能力未运行或不可用时明确标记，不用模拟响应充当成功。最终以实际完成情况更新本表。
