# 2026-10-15 课堂能力升级与验收

本次保留网站免登录、小学至高中和现有学习记录。源码通过独立清敏快照推送 GitHub；原仓库历史和远程地址保持原样。

## 使用入口

| 入口 | 能做什么 |
|---|---|
| 成长课堂 | 小禾姐姐 AI；学习压力、情绪、家人、朋友、校园安全、网络与生活安全、身体与青春期、表达需要八类话题；适龄猜你想问和后续追问 |
| 课件 → 点选对象提问 | 选择文字、图形、带稳定 ID 的互动控件或白板对象，提问时携带真实对象身份 |
| 课件 → 请老师修改 | 修改当前课件对象或互动页；后端校验并持久保存，旧版本不能覆盖新内容 |
| 编辑课件 / 编辑白板 | 拖动、缩放、旋转、双击改字、表格/图表/公式/图片插入、撤销、重做与保存 |
| 老师操作记录 | 查看实际执行结果，失败可重试；互动操作等待当前 iframe 的确认，白板等待保存完成 |
| 导出课程 | PPTX、独立 HTML、课堂 ZIP；HTML / ZIP 可附加现有语音服务生成的老师配音 |
| 我的课堂 → 导入课程 | 导入本项目 JSON / ZIP，建立新课程、新页面和新题库标识；图片先进入本站媒体缓存 |

生成器已接入基础 Three 三维可视化、知识游戏和 JavaScript 编程。三维仅使用本地基础几何与 OrbitControls；不加载外部模型。编程使用可终止 Worker，有运行、停止、输出与超时；不提供 Python 或服务器执行。图片默认使用 `z-image-turbo` 图片接口，每页至多一张自动插图，另可手动生成或上传；不发起视频模型任务。

## 保留的范围

- MP4 是可选项，本版未开放视频导出；HTML / ZIP 是可独立播放的课程文件。
- 导出含离线练习答案和教材白板，不包含课堂聊天、原始资料全文、成绩或提交流水。导入的人工白板作为教材基线，旧板书动作不会重放覆盖它。
- PPTX 保留讲稿备注；互动实验通过 HTML / ZIP 播放。配音选项作用于 HTML / ZIP。
- 成长对话只在当前浏览器按年级保存；课程和练习仍沿用当前公开工作台的共享学习记录。
- 本次未替代真实手机麦克风权限、实际微信扫码登录等需要设备或用户参与的验收。
