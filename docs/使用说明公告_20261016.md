# 使用引导与手机白板

更新：2026-10-16。对应本次 QQ 反馈修复，正式验收结果以本轮交付回执为准。

## 使用引导

首次进入时依次介绍学习主题、年级与方向、已有课程、复习与成长课堂、语音入口和更多工具。当前页面不存在或不可见的目标会跳过；课内深链也可以打开引导。

- 点“知道了”继续；“开始使用”“跳过全部”或 Esc 都会记录已看过。
- 右上角问号可以重播。标记为 `localStorage` 的 `educationagent.onboarding.finished`，只保存在当前浏览器；无痕窗口、清除站点数据或换浏览器会重新引导。
- 气泡按实际尺寸和 `visualViewport` 定位。短横屏和软键盘收缩可视区时，内容可在气泡内部滚动，退出按钮仍可达。
- 高亮框裁剪在可视区内；滚动、窗口及锚点尺寸变化后重新测量。
- 打开时约束键盘焦点并暂时使背景不可交互，关闭后恢复原焦点或问号入口。
- 配色使用当前主题变量。问号位置依据真实课堂头部高度计算，不依赖固定手机头部高度。

入口代码：`desktop-app/src/components/OnboardingGuide.tsx`、`OnboardingGuide.css`、`onboardingGeometry.ts`；由 `App.jsx` 挂载。

## 手机白板与画笔

手机或窄屏首次打开编辑器默认“浏览”。该模式使用只读画布，手指上下滑动不会进入框选，不产生未保存修改。桌面默认“选择”，保留拖动、缩放、旋转和原编辑工具。

“画笔”模式支持颜色、粗细、一笔一撤销、重做及“清除涂画”。清除只移除笔迹，保留课件文字、图片和图形；清除也可撤销。浏览、选择、画笔有明确入口，画画后需要滑动页面时切回浏览。

笔迹保存为现有 `shape` 对象，复用原事务、保存及 JSON/HTML/PPTX 导出。开放笔迹保持透明填充。触摸取消、丢失捕获或切换模式时，未完成笔画不会写入课件。

入口代码：`desktop-app/src/classroom/SlideEditor.tsx`、`FreehandSurface.tsx`、`freehandModel.ts`。
