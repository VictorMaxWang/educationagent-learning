# 使用引导（分步新手引导）

日期：2026-10-16。本文说明本次改动的交互、**合并要点**和验证方式。

> 说明：本轮最初实现的是"一次性公告弹窗"，后按需求改为**分步引导**，弹窗方案的两个文件已删除。本文描述的是当前生效的引导方案。

## 1. 做什么、为什么

面向 7–18 岁学生，第一次进站自动播放一套**分步引导**：逐个高亮页面上的真实元素，弹出气泡讲解，走完后缩成**右上角的小问号**，随时可以重放整套引导。

比起一次性把说明文字全堆出来，分步引导让"这一步讲的是哪里"一眼可见 —— 学生跟着点几下就知道怎么用了。

## 2. 交互

| 行为 | 说明 |
|---|---|
| 首次访问 | `localStorage` 没有标记时自动播放 |
| 每一步 | 高亮一个真实页面元素 + 气泡；气泡在目标下方，空间不够翻到上方；箭头按目标中心对齐 |
| 前进 | 点「知道了」；最后一步是「开始使用」 |
| 中途退出 | 点「跳过全部」或按 Esc —— 与走完一样记为已看过 |
| 走完之后 | 右上角出现 42px 的问号按钮（手机 38px），点击重放整套引导 |
| 记忆 | 仅 `localStorage`，**清浏览器缓存才会重置** |

打开引导时点击遮罩**不关闭**：引导要的是"跟着走完"，不是随手点掉（Esc 与「跳过全部」是明确出口）。

## 3. 八步内容

| 步骤 | 高亮目标 | 标题与内容要点 |
|---|---|---|
| 1 | （居中，无箭头） | 你好！我是小陶 —— 咱们简单逛一圈，很快就能学会怎么用晓陶学伴。 |
| 2 | 主题输入框 | 想学什么，写在这里；也可以上传 PDF、Word 资料，我照你的材料备课。 |
| 3 | 年级与方向选择 | 选你正在读的年级，我就按你的水平讲课；想聊成长话题就换学习方向。 |
| 4 | 我的课堂 | 学过的课都在这儿，点一下接着上次继续学。 |
| 5 | 学习 / 复习 / 成长课堂 | 错题自动进「复习」；成长课堂含心灵与沟通、安全与健康、语言与通识、实践与创造。 |
| 6 | 右下角语音球 | 右下角就是我，说话或打字都行，还能读给你听；课堂里也能直接问老师。 |

## 5. 实现要点

- **锚点用现成的唯一 class 选择器**（`.cr-main-question`、`.cr-create-fields`、`.cr-library`、`.cr-tabs`、`.voice-orb`、`.cr-all-tools`），**不改动任何现有组件** —— 项目页面里没有可用的 id。
- **挖洞高亮用单个元素 + 超大外阴影**（`box-shadow: 0 0 0 9999px`），不是四块遮罩拼接，接缝处不会漏光。
- **锚点解析带逐帧重试**（最多约 200 毫秒）：刚挂载时可能量到零尺寸，那样会把带箭头的步骤全部丢掉、只剩居中气泡，看起来就像"没锚定、背景全暗"。
- **零尺寸守卫**：锚点存在但被 `hidden` 或尺寸为零（语音球会被挂起）时自动跳过该步，不画贴在角落的空框。
- **高亮框不加 transition**：它每帧跟着目标走，加了过渡会在滚动时一直追不上，看起来像没锚住。
- **居中气泡只淡入不位移**：它靠 `transform: translate(-50%,-50%)` 定位，动画若改写 `transform` 会让它先偏一下再跳回中心。
- **配色全部取主题变量，跟随项目七套主题**；主色填充上的文字用主题的 `--on-primary`，保证奶油 / 嫩粉 / 奶油黄这类浅色主色主题下仍可读。

## 6. 合并要点

1. **`App.jsx` 是 645 行的大文件**，也是双方最可能同时改的文件。我的改动只有两行，冲突解决时极易被整段丢掉。合并后确认：
   ```bash
   grep -c "OnboardingGuide" desktop-app/src/App.jsx   # 期望 2
   ```
2. **样式是组件级 CSS**（靠组件自己 `import`），不要挪进全局 `App.css`。
3. **`z-index` 约定**：入口 `150`、引导层 `9999`。参考量：小陶语音球 `160`、课堂头部 `.cr-header` 为 `5`。
4. **入口的 `top` 依赖头部高度**：`top:100px`（课堂头部 88px）、`≤900px → 90px`（头部 77px）、`≤760px → 115px`（手机上头部换行后 `min-height:103px`）。**对方若改了 `.cr-header` 的高度或换行行为，这个值要跟着改**，否则问号会压到头部按钮上。
5. **唯一新增的持久化状态**是 `localStorage` 键 `educationagent.onboarding.finished`（沿用项目 `educationagent.*` 前缀约定）。没有新增接口、配置项、数据库表或服务端依赖，对后端与生成器**零影响**。
6. **两种构建都会显示**：它挂在 App 外壳上，`VITE_PUBLIC_CLASSROOM=true`（公网）与本机版都覆盖。

## 7. 验证

```bash
cd desktop-app && npm run typecheck        # 通过
cd desktop-app && npm run test:classroom   # 128 个前端用例，应全绿
```

`npm run test:classroom` 前若 `public/educationagent-export/player.js` 不存在，先跑 `node ../scripts/build-classroom-export.mjs`——那是构建顺序问题，不是回归。

**手工验收**（自动化覆盖不到视觉）：

1. 打开 `http://localhost:1420`，**首次应自动播放引导**
2. 逐步确认：高亮框是否套住目标、箭头是否指向目标、滚页时是否跟得住
3. 走完或「跳过全部」→ 右上角出现问号 → 点击能重放
4. 刷新页面 → **不应再播**，问号仍在
5. 控制台执行 `localStorage.removeItem('educationagent.onboarding.finished')` 再刷新 → 回到"首次"状态
6. **手机**上（`http://<电脑局域网IP>:1420`）确认：气泡不出屏、按钮好按、问号不与头部按钮重叠
7. 切换 **设置 → 主题**，7 套主题下引导配色都应跟着变

**尚未做的验证**：只在桌面浏览器上看过，**没有在真机上核对**；第 6、7 条要实际跑。

## 8. 文案的边界（不要对外说过头）

- 第 8 步之前那句「课堂里以文字、图片和动手实验为主，**站内也有视频可以看**」是**笼统的**：课程导出为 MP4 的功能明确未开放（`videoExportCapability()` 返回 `available: false`），课堂**新生成**的幻灯片会过滤 video/audio 元素；现在能看到的视频来自 B 站教程匹配、生活企划的热门视频，以及**导入课件**里原本带的视频。
- 第 7 步用「…等等」收尾，是因为公网免登录只放行刷题、图片水印、团队成果实验室（外加英语口语与语法面板），本机版是完整工具集。**两种构建看到的文案相同，实际条目不同**。
- 全部内容只讲"怎么用"，不涉及技术实现、凭据、后台配置。
